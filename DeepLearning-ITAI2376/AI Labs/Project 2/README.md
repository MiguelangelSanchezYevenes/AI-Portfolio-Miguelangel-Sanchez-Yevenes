
## Problem Statement

The goal of this project was to build an image classification system that could correctly identify whether an image showed a puppy or a bagel. The challenge was teaching a computer to recognize visual differences between two classes that can sometimes appear similar in shape, color, or texture. We focus on using CNNs to process images and improve classification accuracy.

## Approach and methodology

First, the dataset was downloaded and organized into training, validation, and testing folders. Image preprocessing and data augmentation techniques are used to help the model improve in performance and reduce overfitting. Training performance was monitored through accuracy and loss graphs.

## Results and evaluation

The CNN models successfully classified images of puppies and bagels with very high accuracy. The transfer learning model performed better overall because it used features learned from large image datasets. We were also shown the models could correctly identify most images with few mistakes.
